# to-do-list-application
📋 Responsive To-Do List App
A simple and elegant To-Do List Web App built with just HTML, CSS, and JavaScript. Easily accessible on both desktop and mobile browsers, it allows users to manage daily tasks efficiently.

✨ Features
✅ Add new tasks

🕒 Mark tasks as Pending or Completed

❌ Delete tasks when no longer needed

📱 Fully mobile-responsive design

🎨 Clean and modern UI

🛠 Built With
HTML5
CSS3
Vanilla JavaScript
